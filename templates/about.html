Checking for new versions

Typeset Studio can look once a day to see whether a newer release exists, and tell you here. It never installs anything by itself — you download and run the installer when you choose to.

The check is {{ 'on' if checks_on else 'off' }} {%- if not checks_on %}, which is the default: this app talks to nobody unless you ask it to{% endif %}.

  • It sends a plain request to {{ feed }} and reads the version number.
  • Nothing about you, your books or your usage is sent — there is no account, no identifier and no telemetry anywhere in this app.
  • If you are offline, or the feed can't be reached, nothing happens and nothing is reported.
