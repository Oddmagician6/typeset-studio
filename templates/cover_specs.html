How to build it
  1. Make a new document exactly {{ '%.4f'|format(W) }} × {{ '%.4f'|format(H) }}" ({{ px[0] }} × {{ px[1] }} px at {{ dpi }} dpi). Keep every photo at least {{ dpi }} dpi at the size it prints.
  2. Either add guides at the positions above, or place the blank template as the bottom layer, lock it, and design on top.
  3. Run background colour and art all the way to the outer edge — the pink bleed is cut off, so nothing there will survive.
  4. Keep title, author, blurb and faces inside the green safe areas. The front cover is on the right, the back on the left.
    5. {% if g.spine_text %}
  5. Spine text reads top to bottom on most English-language books. Keep it inside the spine's safe area — a spine is rarely cut perfectly centred.
    6. {% else %}
  6. Leave the spine free of text: at {{ spec.pages }} pages it is too narrow for {{ rc.label }} to print any.
    7. {% endif %} {% if g.wrap %}
  7. The blue turn-in folds round the boards and is glued down — extend the art into it, but put nothing there you need to see.
    8. {% endif %} {% if g.hinge %}
  8. Keep type out of the grey hinges; that is where the case bends.
    9. {% endif %} {% if g.flap %}
  9. Flap copy goes inside the flaps' safe areas: a blurb on the front flap, an author note on the back.
    10. {% endif %}
  10. Leave the barcode area plain. {% if spec.retailer == 'kdp' %}KDP prints an ISBN barcode there for you if your file doesn't carry one.{% else %}Place your ISBN barcode there, or leave room for your printer to add one.{% endif %}
  11. Hide or delete the template layer, then export a single-page PDF with fonts embedded and no crop marks. PDF/X-1a is the safest choice if your app offers it.
  12. Upload it as the cover file, separately from the interior. {{ rc.hardcover_note if spec.binding != 'paperback' else rc.note }}
