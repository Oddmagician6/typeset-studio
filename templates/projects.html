Getting started

Set your first book

A project remembers a book's manuscript, style, and title-page settings, so you can rebuild the PDF any time without re-entering anything. Two ways in:

  1. Start a draft — type a title in New draft title above and write in the built-in editor.
  2. Or Set a book — pick a style, drop in a manuscript you already have, and compose a print-ready PDF.
  3. On the result page, hit Save as project — it lands here, ready to regenerate or hand off to KDP / IngramSpark.
